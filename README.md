## 📌 About The Project

**Flesha AI** is a modern web-based college information assistant designed to help students quickly find information related to college life, academics, admissions, examinations, campus facilities, careers and student services.

The project provides an interactive chatbot interface where students can type questions and receive instant responses.

Flesha AI is designed with a clean, responsive and user-friendly interface that works across desktop and mobile devices.
